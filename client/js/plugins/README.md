# client/js/plugins/

**Purpose:** One interactive widget per `_name.js`, bound via `data-role` and Plugin lifecycle.

**Put here:** Widget `init` / `load` / `render` / `destroy`; register in `index.js`.

**Do not put here:** SOA → metadata mapping (`helpers/`), page-level routing (`client/pages/`).

**Canonical docs:** [client.md](../../../client.md), [docs/client-js-lifecycle.md](../../../docs/client-js-lifecycle.md), [docs/folder-ownership.md](../../../docs/folder-ownership.md).
