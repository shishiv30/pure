# client/js/core/

**Purpose:** Client runtime primitives — Page/Plugin pipeline, events, router, request, defBool/defEnum, DOM hooks.

**Put here:** Cross-page framework utilities reused by plugins and page entries.

**Do not put here:** Page-specific business (e.g. demo detail fetch rules), SOA mapping (`helpers/`), widget UI (`plugins/`).

**Canonical docs:** [docs/client-js-lifecycle.md](../../../docs/client-js-lifecycle.md), [client.md](../../../client.md), [docs/folder-ownership.md](../../../docs/folder-ownership.md).
