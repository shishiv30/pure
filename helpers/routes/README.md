# helpers/routes/

**Purpose:** Shared route manifests consumed by server routes and client Router (single source of truth for URL shapes).

**Put here:** Pattern constants, `create*RegExp` helpers, param index maps (e.g. `demoSpaRoutes.js`).

**Do not put here:** Express handlers, `fetch`, controller `get()` logic.

**Canonical docs:** [docs/routes-reference.md](../../docs/routes-reference.md), [docs/folder-ownership.md](../../docs/folder-ownership.md).
