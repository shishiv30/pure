# helpers/

**Purpose:** Pure transforms and shared contracts (geo, listing metadata, article comps, path/URL, route manifests).

**Put here:** Mapping functions, shared regex/route manifests, webpack loaders that only transform source.

**Do not put here:** Express handlers, seed/mock payloads (`data/`), DOM/runtime (`client/js/core/`).

**Canonical docs:** [docs/folder-ownership.md](../docs/folder-ownership.md), [docs/listing-data-pipeline.md](../docs/listing-data-pipeline.md), [docs/index.md](../docs/index.md).
